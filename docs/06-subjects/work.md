# Subject — Work (Portugal → Germany)

## Traveling (< 3 months)

**Key rule:** as an EU citizen you may work in Germany **without a work permit**. But a *business
trip* ≠ *taking up employment*: attending a meeting/conference is fine; being paid by a **German
employer** (or running a local operation) is not "traveling" — it triggers the Moving/work rules.

**Posted worker (sent temporarily by your Portuguese employer):** your social security **stays in
Portugal** — you need an **A1 certificate** (see `social-security.md`), valid up to **24 months**.

### Documents
| Doc | Notes |
|---|---|
| Valid ID / passport | only hard requirement |
| A1 certificate (if posted) | from Segurança Social (PT) — proves PT social-security coverage |
| Work permit | **not needed** (freedom of movement) |

### Info
- No work permit, no registration for a short stay.
- Business conference ≠ employment — but a local employment arrangement needs the Moving flow.

## Moving (> 3 months)

**Key rule:** an employment contract is your proof of the right to stay (Art. 7(1)(a) Directive
2004/38/EC). No work permit, no residence permit.

### Procedures
1. Sign employment contract (or self-employment registration — see `../03-cases/cases/move-self-employed.md`).
2. **Qualification recognition** — only for **regulated professions** (doctor, lawyer, teacher,
   nurse, engineer, …): check **anabin** database / **ZAB** Statement of Comparability (€208) /
   **BQFG** recognition / **Approbation** (health professions). Non-regulated roles: no recognition.
3. Anmeldung (14 days) → Steuer-ID (auto).
4. Employer registers you for **health insurance + social security (Lohnsteuer payroll)**.
5. Bank account for salary.

### Deadlines
| Trigger | Action | Window |
|---|---|---|
| Move-in | Anmeldung | 14 days |
| Before starting regulated work | qualification recognition | before start |
| As of start | employer registers insurance + payroll | legal requirement |

### Documents
| Doc | Issuer | URL |
|---|---|---|
| Employment contract | employer | — |
| Qualification recognition (regulated) | anabin / ZAB / competent body | https://anabin.kmk.org · https://zab.kmk.org |
| Anmeldung → Meldebescheinigung | Bürgeramt | service.berlin.de |
| Steuer-ID | BZSt (auto) | https://www.bzst.de |
| Rentenversicherungsnummer | Deutsche Rentenversicherung | https://www.deutsche-rentenversicherung.de |
