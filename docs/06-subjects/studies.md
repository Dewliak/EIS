# Subject — Studies (Portugal → Germany)

## Traveling (< 3 months)

- **Short course / exchange / language school:** no registration, no visa — valid ID only.
- EHIC covers necessary healthcare.
- No enrolment formalities for a genuine temporary stay.

### Documents
| Doc | Notes |
|---|---|
| Valid ID / passport | only hard requirement |
| EHIC | recommended (healthcare) |

## Moving (> 3 months)

**Key rule:** enrolment in a recognized institution + sufficient resources + health insurance =
right to stay (Art. 7(1)(c) Directive 2004/38/EC). **No visa, no blocked account** (that's non-EU).

### Procedures
1. **Admission** — your Portuguese school-leaving/degree certificates are recognized under the
   Lisbon Convention; apply to the German university.
2. **Health insurance** — join a public insurer on the **student rate** (≈€80–130/month under 30)
   **before** enrolment.
3. **Enrol (Immatrikulation)** — submit insurance proof + ID → get matriculation confirmation.
4. **Anmeldung** (14 days) → **Steuer-ID** (auto).
5. **Bank account** for rent/expenses.
6. You may **work part-time** while studying (no hours cap for EU citizens).

### Deadlines
| Trigger | Action | Window |
|---|---|---|
| Move-in | Anmeldung | 14 days |
| Before enrolment | health insurance proof | before enrolment |
| Per semester | re-enrol + semester fee | per university |

### Documents
| Doc | Issuer | URL |
|---|---|---|
| Admission / enrolment proof | university | https://www.daad.de (course search) |
| Student health insurance | TK / AOK / Barmer | https://www.tk.de |
| Proof of resources | bank statements | — |
| Anmeldung → Meldebescheinigung | Bürgeramt | service.berlin.de |
