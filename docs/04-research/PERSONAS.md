# 01 — Personas

Two personas to exercise both cases. Both are **Portuguese citizens** (EU — freedom of
movement applies, no visa). Destination = **Germany** (Berlin).

---

## Persona A — Traveling (short stay)

| Field | Value |
|---|---|
| Name | Tiago |
| Age | 27 |
| Origin | Portugal (Lisbon) |
| Destination | Germany (Berlin) |
| Intent | **Traveling** — 3 weeks, visiting + a work conference |
| Employment | Employed (marketing, Lisbon company) |
| Dependents | None |
| Length of stay | 3 weeks (< 3 months) |

**What he needs to do:**
- Nothing formal for residence — valid ID/passport only (≤3 months, no conditions, no registration).
- Carry **EHIC** (European Health Insurance Card) for state healthcare during the temporary stay.
- Optional private travel insurance for non-covered gaps.
- No Anmeldung, no tax ID, no bank account needed for a 3-week stay.

**Pain points the platform solves:**
- "Do I need to register for 3 weeks?" → No (clear answer up front).
- "Is my Portuguese EHIC valid in Germany?" → Yes for emergency/temporary state care.
- "When does the moving-in clock start?" → The 14-day Anmeldung rule only when he actually *moves*.

---

## Persona B — Moving in (long stay)

| Field | Value |
|---|---|
| Name | Beatriz |
| Age | 31 |
| Origin | Portugal (Porto) |
| Destination | Germany (Berlin) |
| Intent | **Moving in** — permanent relocation for a job |
| Employment | Employed (software engineer, signed DE contract) |
| Dependents | None |
| Length of stay | Indefinite (> 3 months) |

**What she needs to do (order matters):**
1. **Housing** → signed rental contract → get **Wohnungsgeberbestätigung** (landlord confirmation).
2. **Anmeldung** (address registration) at the **Bürgeramt**, within **14 days** of moving in.
3. Get **Meldebescheinigung** (registration certificate) + automatic **Steuer-ID** (tax ID) by mail.
4. **Health insurance** — mandatory, join a public insurer (or private if eligible).
5. **Social security number** (Rentenversicherungsnummer) — issued via employer/insurer.
6. **Bank account** (IBAN) — after Anmeldung.
7. No residence permit needed (freedom of movement) — but foreigners authority may ask for
   employment proof.

**Pain points the platform solves:**
- The **14-day Anmeldung window** (fine up to €1,000).
- **Wohnungsgeberbestätigung ≠ tenancy agreement** (a common trap — the lease alone is not enough).
- The ordering: housing → Anmeldung → tax ID → insurance → bank.
